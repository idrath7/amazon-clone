# Amazon Clone — E-Commerce Website

A responsive Amazon-inspired e-commerce website built using **HTML5 and CSS3**.

This project recreates the front-end design of the Amazon homepage, including the navigation bar, search bar, product categories, promotional banner, shopping cards, and footer.

The main goal of this project is to practice front-end web development, CSS layouts, responsive design, and website structure.

## Project Overview

**Project Name:** Amazon Clone  
**Project Type:** Front-End Web Development  
**Technologies:** HTML5, CSS3, Font Awesome  
**Design:** Responsive E-Commerce Homepage  
**Status:** Front-End UI Completed

This project focuses on creating a clean, organized, and responsive shopping website inspired by Amazon.

## Features

- Amazon-inspired navigation bar and logo
- Delivery location section
- Search bar with category dropdown
- Sign-in and account section
- Returns and orders section
- Shopping cart icon
- Secondary navigation menu
- Promotional hero banner
- Eight shopping category cards
- Product category images
- Hover effects and interactive styling
- Multi-column footer
- Responsive layout for desktop, tablet, and mobile
- Organized images folder
